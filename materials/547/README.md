# 文字比较目录和持久索引起点

在本目录运行 `python3 demo.py`。`collations.py` 是供独立导入程序使用的比较目录，`store.py` 使用真实 SQLite B-tree 提供文字取数；当前同名比较回调可以替换，但已有索引没有随之重建。原始普通大小写取数可工作，变化后会遗漏 accent-insensitive 等价的行。代码只是正常起点及可复现缺口，尚未实现旧版本持久目录、固定读句柄或迁移发布。

本题只处理题面指定的两选项 Unicode 规则，不声称完整 ICU 或任意 locale。样例数据由 demo.py 在独占临时目录真实写入 SQLite；不需要外部服务。内部作者探针不属于候选起点，不作为目标答案交付。
